# Ideas

## Thoughts

- Side-view 2D platformer sidescroller
- Metroid-vania-ish
- Sci-fi theme with slight high fantasy influence (melee weapons mostly, laser sword)
- Creature enemies (re-themed mythical creatures as sci-fi)
- High difficulty platformer (annoying stupid silk song)
  - Really high quality movement/physics handling as in HK/SS
- Focus on difficult/interesting level designs before enemies and complex mechanics
- Not turn based, real-time action/fights
- Larger than life backgrounds (parallax)

- Sci fi sounds good
